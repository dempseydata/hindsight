## Resolution

**Yes — produced.** The shipped UI's design system is recorded as a derived product `DESIGN.md` at the repo root, generated by Impeccable's documenter from the post-floor-audit surface (#47). Commit 9e06ab4.

Decisions (grilled):
- **Produce it** — the house clause "keep a product copy if tooling needs one" is satisfied: Impeccable's live hooks and audit only run their design-system drift detection (undocumented colours, undeclared faces, off-scale radii) against a `DESIGN.md`; without one that layer was inert (#47 ran floor rules only).
- **Repo root** — Impeccable's primary lookup path (`design/` is not searched, so co-locating with tokens.css would hide it from the tooling).
- **Authority unchanged** — `design/tokens.css` remains the sole direction contract; on conflict tokens.css wins. `DESIGN.md` opens with a header stating this and the re-derive rule: re-run the documenter whenever tokens.css or the visual system changes. Never hand-edited.
- **Recorded as an addendum to ADR-0007**, not a new ADR.
- The `.impeccable/design.json` sidecar was generated (staleness check clean) but stays **untracked**, like the rest of `.impeccable/` — derived cache, regenerated by `/impeccable document`.

Drift observed by the documenter, documented rather than fixed:
- `--o-axis` now has no text call site (axis text ships in `--o-dim` per #47); recorded as a reserved non-text chart-line role.
- `--o-accent-ink`, `--o-caution`, `--o-caution-text`, and bright `--o-ok` ship in every page's `:root` but have no active call site — recorded as reserved contract roles, not silently canonized.
- Type ramp, spacing rhythm, spark geometry, hover-lift distance, and the 2px chip radius live as literals in serve.py's CSS, not in tokens.css (chip radius exists there only as a comment). No colour literals anywhere — the token-only ink rule holds as shipped.
